# Live Better · Sống tốt hơn

A Nuxt 4 reader for English and Vietnamese translations of [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter), with 34 chapters and 767 entries from the original Chinese edition.

Read the [website](https://hoanghadu.github.io/how-to-live-better/) or see the [setup, translation and attribution guide](docs/README.md). The AI-generated translations are marked as unreviewed.
